# Gain-Graph 📊

Real-time gain bar analytics web app for YouTube, Roblox, TikTok, Twitter, and Instagram.

## ✨ Features
- **4 Realtime Gain Bar Graphs**:
  - **1s Gain**: Second-by-second (tick-by-tick) rate of change.
  - **1m Gain**: 1-minute interval gains.
  - **1h Gain**: 1-hour interval gains.
  - **1d Gain**: 24-hour daily gains.
- **Multi-Entity Tracking**: Track 1, 2, 3 or more channels/games/groups simultaneously.
- **Live Animated Odometers**: YouTube Studio, SocialBlade, and Akshat Mittal font & styles.
- **Bar Graph Customization**: Visible bar counts (5 to 100), bar gap/spacing, corner radius, solid/gradient/neon fills, stepped Y-axis.
- **🎥 OBS Stream Mode**: Clean overlay mode + `?obs=true` URL support.
- **LocalStorage Auto-Save**: Preserves channels, styling, and gain history.
